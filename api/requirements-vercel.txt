# What Vercel installs (see api/vercel.json → installCommand).
#
# Same runtime deps as requirements.txt, PLUS the private framework — which
# cannot be the `-e ../../solo-founder-crew` path dependency of
# requirements-local.txt, because the builder has no sibling checkout. It comes
# from GitHub instead, authenticated by SFC_GITHUB_TOKEN (a fine-grained,
# read-only PAT set as a Vercel environment variable). pip expands ${...} in
# requirements files, so the token never lands in git.
#
# This file is deliberately NOT reachable from requirements-dev.txt: CI has no
# token and needs none — the tests fake the CrewGateway at the seam.
-r requirements.txt
solo-founder-crew @ git+https://${SFC_GITHUB_TOKEN}@github.com/liapisn/solo-founder-crew.git@main
